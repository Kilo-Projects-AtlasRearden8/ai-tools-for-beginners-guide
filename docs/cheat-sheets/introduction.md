# AI Tools for Beginners — Quick Reference

## What is AI?
Software that does things needing human thinking: writing, summarizing, creating pictures, reading aloud. No programming needed — if you can search the web, you can use AI.

| Safety & privacy | Staying safe while exploring |

## Ground rules
- **AI makes mistakes** — always double-check important facts
- **AI is not a doctor/lawyer/accountant** — general info only, never medical advice
- **Don't share secrets** — no passwords, bank info, SSN, health details
- **You're in charge** — stop anytime, delete account, opt out of data training

## How to use
1. Read Setup first if new to AI

# Audio Tools — Quick Reference

## Two main types
- **Text-to-speech:** reads text aloud (natural voices)
- **Speech-to-text:** writes down what you say

## Free tools to try

**Text-to-speech:**
- **Edge Read Aloud** — built into Edge browser (free)
- **NaturalReader** — naturalreader.com (free tier)
- **ElevenLabs Reader** — elevenlabs.io (free tier, very natural)

**Speech-to-text:**
- **Google Docs voice typing** — Tools > Voice typing (free)
- **Apple dictation** — built into iPhone/iPad/Mac
- **Word dictate** — Dictate button in Word (free with account)
- **Otter.ai** — otter.ai (free tier for conversations)

## Step-by-step: webpage read aloud (Edge)
1. Open Edge, go to any page/PDF
2. Click Read Aloud icon in address bar (speaker/A with sound lines)
3. Choose voice and speed
4. Press play

## Step-by-step: speech to text (Google Docs)
1. Open docs.google.com in Chrome, sign in
2. New document → Tools > Voice typing
3. Click mic, speak clearly
4. Click mic to stop, edit as needed

## Tips
**Text-to-speech:** Try voices, slow speed, use headphones
**Speech-to-text:** Speak normally, say "period/comma/new line," quiet room, always re-read

## Watch out for
- **Voice cloning scams:** urgent call from "family" asking money — hang up, call back on known number
- Don't upload private recordings (medical, legal, family)
- Transcripts make mistakes — check names, numbers, medications
- Not a substitute for doctor/nurse/pharmacist

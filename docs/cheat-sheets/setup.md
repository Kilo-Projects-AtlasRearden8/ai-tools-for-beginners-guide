# Setup — Quick Reference

## What you need
- Device (computer, tablet, phone)
- Browser (Chrome, Edge, Safari, Firefox)
- Email address you own
- ~20 minutes

## Step 1: Email
Have one? Done. Need one? Create free at gmail.com or outlook.com. Write it down on paper.

## Step 2: Pick ONE tool to start
- Chatbots: gemini.google.com, claude.ai, copilot.microsoft.com
- Images: designer.microsoft.com, firefly.adobe.com
- Audio: Edge Read Aloud, Google Docs voice typing

## Step 3: Create account
1. Click "Sign in" / "Get started"
2. Enter email
3. Create memorable but hard-to-guess password (write hint on paper)
4. Click confirmation email link
5. Phone verification? Some require, some optional

## Step 4: Bookmark it
- Chrome/Edge: star icon or Ctrl+D / Cmd+D
- Safari: Share → Add Bookmark
- Firefox: star icon

## Step 5: Try something small
- Chatbot: "Good weeknight dinner with chicken?"
- Image: "Sunny garden, blue flowers, watercolor"
- Audio: Edge Read Aloud on any page

## Track accounts (on paper)
| Tool | Website | Email | Password hint |
|------|---------|-------|---------------|
| Gemini | gemini.google.com | me@gmail.com | [hint only] |

Never store real passwords in files. Paper notebook is safer.

## If stuck
- Forgot password? "Forgot password" link
- Site won't load? Refresh or try another browser
- Not sure what to type? Start with "Hello"
- You can quit anytime — close tab, delete account, walk away

## Next
When comfortable, try another tool. Read Safety & Privacy before exploring further.

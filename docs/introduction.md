This manual is for anyone who wants to start using AI tools but doesn't know where to begin. It is written in plain English, step by step, the way a friend would explain it. No jargon. No condescension.

It was created by **Asdale Dynamics, LLC**, the same team behind *The Massive AI Manual* and dylanasdale.github.io.

## What is AI, really?

AI (artificial intelligence) is software that can do things that usually take human thinking — like writing an email, summarizing a long letter, suggesting a reply to a text, creating a picture from a description, or reading text out loud.

You do not need to be a programmer to use it. If you can type into a search box, you can use these tools.

## A few ground rules

- **AI makes mistakes.** It can get dates, names, and facts wrong. Always double-check anything important.
- **AI is not a doctor, lawyer, or accountant.** It can share general information, but it cannot give you professional advice. This manual never gives medical advice.
- **Don't share secrets.** Never type passwords, bank account numbers, Social Security numbers, or private health details into an AI tool.
- **You are in charge.** You can stop using any tool at any time, delete your account, and ask companies not to use your data to train their models where they offer that option.

## How to use this manual

Read the [setup page](setup.html) first if you have never used an AI tool before. Then pick the topic that sounds most useful to you and follow the steps. Each page stands on its own, so you can jump around.

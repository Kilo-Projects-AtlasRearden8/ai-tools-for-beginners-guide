# STATUS

## What was built

A beginner-friendly AI tools manual published by Asdale Dynamics, LLC, with both Markdown source files and a generated static HTML site.

### Manuals (`docs/`)
- `introduction.md` — What AI is, how to think about it, ground rules
- `chatbots.md` — AI assistants you talk to by typing (Gemini, Claude, Copilot, etc.)
- `image-generators.md` — Type words, get pictures (Designer, Firefly, Leonardo, etc.)
- `writing-assistants.md` — Help with emails, letters, resumes (Grammarly, Hemingway, Google Docs, etc.)
- `audio-tools.md` — Text-to-speech and speech-to-text (Edge Read Aloud, NaturalReader, Google Docs voice typing, etc.)
- `setup.md` — Step-by-step getting started from scratch
- `safety-privacy.md` — Staying safe: no secrets, double-check facts, scams to know

### Cheat sheets (`docs/cheat-sheets/`)
One-page printable summaries for each of the 7 topics above.

### Static site (`site/`)
Same content as HTML, generated by `build_site.py`. Includes `style.css` for clean, readable styling. All pages credit Asdale Dynamics, LLC and carry the © 2026 copyright.

### Build tooling
- `build_site.py` — Converts Markdown to HTML using the Python `markdown` package
- `style.css` — Shared stylesheet (also at `site/assets/style.css`)
- `tests/verify_site.py` — 7 tests verifying file existence, HTML structure, credits, copyright, and no secrets

### Licensing and credit
- `LICENSE` — MIT License, copyright line exactly: `Copyright (c) 2026 Asdale Dynamics, LLC`
- `README.md` — Credits Asdale Dynamics, LLC throughout

## How to run it

### Read the manuals
Open any file in `docs/` in a text editor, or open any `.html` file in `site/` in a web browser. No internet connection needed once files are on your computer.

### Rebuild the static site
```
python3 build_site.py
```
Requires: `pip install markdown`

### Run verification tests
```
python3 -m pytest tests/verify_site.py -v
```
All 7 tests pass.
